РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ

While Analyzer выполняет синтаксическую проверку конструкций while в рамках поддерживаемого подмножества C++. Документ должен содержать один внешний цикл; вложенные циклы допускаются. Проверка запускается командой «Пуск → Анализ».

Рабочая область

Редактор предназначен для ввода и изменения исходного текста. Слева отображаются номера строк. Область «Результат анализа» содержит сообщение об успешной проверке либо перечень ошибок с указанием строки и столбца. Высота областей регулируется перемещением разделителя.

Ошибочные фрагменты выделяются красным цветом; пропуски обязательных элементов отмечаются маркером. При изменении текста подсветка сбрасывается. Для обновления результатов необходимо повторно выполнить анализ.

Панель инструментов

Панель расположена под строкой меню и обеспечивает доступ к основным командам. Назначение кнопки отображается во всплывающей подсказке при наведении указателя.

Меню «Файл»

Создать (＋) — очищает редактор и результаты анализа, создаёт новый документ.
Открыть (📂) — загружает файл .txt или .cpp в редактор. Анализ выполняется отдельной командой.
Сохранить (💾) — записывает содержимое редактора в текущий файл. Для нового документа открывается диалог выбора имени и расположения файла.
Выход — завершает работу приложения.

При создании и открытии документа, а также при завершении работы запрос на сохранение изменений не выводится. Сохранение выполняется командой «Сохранить».

Меню «Правка»

Отменить (↶) — отменяет последнее изменение текста.
Повторить (↷) — восстанавливает отменённое изменение.
Вырезать (✂) — перемещает выделенный фрагмент в буфер обмена.
Копировать (⧉) — копирует выделенный фрагмент в буфер обмена.
Вставить (▣) — вставляет содержимое буфера обмена в позицию курсора или заменяет выделенный фрагмент.

Пункт «Текст»

Открывает PDF-отчёт курсовой работы в системном приложении для просмотра PDF. Файл report.pdf размещается в каталоге приложения. До добавления окончательной версии доступен временный документ. При отсутствии файла выводится сообщение об ошибке.

Меню «Пуск»

Анализ (▶) — выполняет проверку текущего содержимого редактора и обновляет список ошибок и подсветку. Команда не исполняет исходный код и не сохраняет документ.

Меню «Справка»

Вызов справки (?, F1) — открывает руководство пользователя. Текст доступен для выделения и копирования. Клавиша Esc закрывает окно справки.
О программе (i) — отображает название и назначение приложения.

Меню «Локализация»

Русская / English — устанавливает язык интерфейса, справки и результатов анализа. Изменение применяется немедленно; содержимое редактора сохраняется.

Меню «Вид»

Размер текста → Увеличить шрифт / Уменьшить шрифт — изменяет размер текста редактора, нумерации строк и результатов с шагом 1 пиксель. Диапазон размера шрифта редактора: 8–40 пикселей.

Ctrl + колесо мыши (Command + колесо мыши в macOS) — изменяет масштаб основного интерфейса в диапазоне 70–180%.
